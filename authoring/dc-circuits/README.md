# Skill Solar System — DC Circuits Batch 01

This package is for Claude Code to integrate into the existing local project. It is not a replacement application and its authoring JSON cannot be loaded with Open map.

Start with CLAUDE-INSTRUCTIONS.md. The package contains:
- dc-circuits-batch-01.json: 26 skill candidates, 53 prerequisite links, 5 supporting links, 26 overview-related links, and source references.
- COVERAGE.md: complete checklist, inventory decisions, deferred coverage, and limitations.
- validate_batch.py: standard-library, read-only pre-integration validation against a supplied master.
- validation-report.json: results from the supplied 1,686-node / 4,882-edge baseline.
- author_batch.py: reproducible authoring source for the content JSON; not a map importer.

All original nodes and markings are to be retained. New narrower abilities are unmarked. The same skill appearing in an overview does not automatically make the narrower skill proficient.

Expected baseline totals after full integration: 1,712 nodes and 4,966 edges. These totals include preserved overview nodes and are not counts of fully independent competencies.

Runtime level/position assignment, app build/tests, and Electron visual validation remain for Claude on the current project. No personal maps or proficiency records are included in this package.
