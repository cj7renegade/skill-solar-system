## Robotics conventions and scope

Keep the existing Robotics domain. Use right-handed frames and column vectors. T_AB maps coordinates from B into A. Joint q2 in the two-link examples is relative to link 1. Link lengths are positive, the base is fixed, and the tool point lies at the second link end unless an offset is explicitly specified. Derivatives and joint rates use radians. The 2-by-2 Jacobian in this package maps joint rates to Cartesian tip-position rates; it is not a general six-dimensional spatial twist Jacobian.

Keep the old broad overview nodes unchanged. New skills start unmarked even when their overview is Yes. Read current descriptions and reconcile semantic equivalents: descriptions mentioning an operation are not automatically a separate proficiency record, but do not add an identical narrow record if one already exists. The package does not require completion of the coverage-inventory documentation pass.

Sources support conceptual coverage; the planar examples and prerequisite links are editorial. No application or hardware execution is implied by solving kinematic equations. Joint-limit checks do not replace collision, dynamics, or trajectory checks.

Run check_examples.py as well as validate_batch.py. The former checks the package equations; it does not test renderer or app code. Numerical checks include known forward poses, both regular inverse branches, finite-difference Jacobian agreement, determinant identity, and a transform round trip.

Handle the equal-link origin target separately: the usual shoulder formula is undefined and configurations are nonunique. Do not blindly clip truly unreachable inverse-cosine arguments into range; distinguish a stated rounding tolerance from physical unreachability. Robot joint winding limits cannot always be replaced by principal-angle wrapping.
